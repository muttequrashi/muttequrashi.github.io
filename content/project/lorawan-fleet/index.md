Industrial sensor fleet built for an EU industrial client. Battery-powered field nodes on custom ESP32-class PCBs communicate over LoRaWAN to a local gateway, which forwards structured telemetry to a cloud back-end. Signed-URL access from operator dashboards. Covers hardware, firmware, cloud back-end, and field-ops UX.
